# Medium post checklist (deeper advice)

## Title
- 50–100 characters. Specific beats clever. Numbers and "I tried / I tested" framing work well.
- Put the main keyword (e.g. "Python 3.15", "Gemma 4") in the first half.

## Subtitle
- One sentence under the title that says who it is for and what they get.

## Opening
- First 3 lines decide if people keep reading. Start with a problem or a surprising result,
  not with a definition.

## Structure
- A heading every 200–350 words. Headings should read like a summary when skimmed.
- One idea per section. End sections with a one-line "Lesson:" or takeaway.

## Visuals
- A cover image (first image) and at least one image per ~600 words.
- Charts with real numbers beat stock images.

## Code
- Short, runnable snippets. Link the full code on GitHub.

## Length
- 6–12 minute reads (~1,400–3,000 words) do best for technical tutorials.

## Distribution
- Submit to a relevant publication. Use all 5 tags. Share a friend link for non-members.
